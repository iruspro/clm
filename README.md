# clm — Command Line Money

**clm (Command Line Money)** is a terminal-based personal finance manager written in **Rust**.
The application provides a full-featured financial tracking system accessible entirely from the command line. It allows users to manage expenses, income, accounts, and investment assets while keeping data locally stored.

The goal of the project is to build a practical CLI application that combines personal budgeting and investment tracking in a lightweight and efficient interface.

## Features

* Track **income and expenses**
* Manage multiple **accounts** (cash, bank, etc.)
* Support for **assets and investments**

  * cryptocurrencies
  * stocks
  * other financial instruments
* **Portfolio tracking** with profit/loss monitoring
* **Transaction categorization**
* **Budgeting and spending limits**
* **Financial summaries and statistics**
* Local data storage using DB

## Interface

`clm` is designed as a **command-line interface (CLI) application**, allowing users to interact with the system through a structured terminal interface. The program focuses on speed, simplicity, and scriptability.

## Project Goals

This project focuses on:

* building a complex and practical application in **Rust**
* designing modular and maintainable code
* implementing persistent data storage
* developing a clear and efficient CLI user interface
* handling financial data and portfolio calculations

## Technology

* **Rust**
* CLI interface
* **PostgreSQL / SQLite** database
* structured financial data models
